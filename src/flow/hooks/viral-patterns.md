# Viral hook patterns — the first 2 seconds

Short-form retention collapses in the first 1.5 seconds. Gemmah's
beat sheet is always **0.0-2.0 hook / 2.0-6.0 body / 6.0-8.0 payoff**.
The hook is the only part we A/B test.

## Hook templates (pattern-interrupt first)

Pick one per video. The generator patches the hook from the scored
CHANGELOG delta's emotion class.

| Class | Template | Example |
|---|---|---|
| **awe** | "wait — [they / Claude] just shipped…" | "wait — Claude just shipped something wild" |
| **surprise** | "no one is talking about [delta]" | "no one is talking about the /fire endpoint" |
| **FOMO** | "if you're not using [X] yet, you're so behind" | "if you're not using routines yet, you're so behind" |
| **frustration** | "this changelog entry is genuinely stressing me out" | "this changelog entry is genuinely stressing me out" |
| **insider** | "ok so this flag is doing something weird" | "ok so `--bare` is doing something weird" |

## Rules

- **Never** open with "hey guys" / "what's up everyone" / "today
  we're going to talk about."
- **Never** open with a question the viewer has to think about ("did
  you know…"). Pattern-interrupts are declarative.
- First word should be one of: *wait, no, ok, this, if, why, they,
  Claude*. Nothing longer than one syllable if you can help it.
- Eyes to camera from frame 1. No opening pan-in.

## Body (2.0–6.0)

- One specific claim from the CHANGELOG. No recap of the whole
  release. Pick the ONE delta that scored highest on the emotion
  rubric.
- Say the flag/command/feature name **once, clearly** — viewers will
  screenshot.
- Cut away to nothing — single-shot, no B-roll. The location does the
  work.

## Payoff (6.0–8.0)

- A one-line consequence or stance, not a CTA.
- "so like… watch this space" is OK; "smash that like button" is
  banned.
- Optional: a micro-reaction at the very end (small head-shake,
  glance down) — gives the edit a clean exit.

## What NOT to do

- No on-screen text overlays generated by Veo — Veo's text rendering
  is unreliable and will sink credibility. Text goes on in post.
- No music bed with lyrics — Veo hallucinates lyric content.
- No direct handling of any phone / prop with visible text.
- No full sentences that state the emotion — *show* the reaction.
  "I'm so shocked" = fail. Wide eyes + 2-beat pause = pass.
